## Локальный запуск

Требуется Python 3. В терминале перейдите в папку проекта и выполните:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8000/ в браузере. Для остановки сервера нажмите Ctrl+C.
